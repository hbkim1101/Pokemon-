# RPG Maker XP 프로젝트

- `MyPokemonGame/` — 현재 편집 프로젝트. 로컬 PC에서 `Game.rxproj`를 RPG Maker XP로 열고 `Game.exe`로 실행합니다. 라이선스 조건 때문에 Git에는 포함하지 않습니다.
- `Essentials-v21.1-base/` — 로컬 v21.1 원본 베이스. 새 프로젝트를 만들 때 복사 입력으로 사용하며, Git에는 포함하지 않습니다.

이 폴더 아래의 게임 프로젝트는 기존 Pokémon Arena Git 저장소의 범위와 분리되어 로컬에 저장됩니다. 큰 런타임/그래픽 에셋이 Arena 저장소에 실수로 추가되지 않도록 `.gitignore`에서 제외했습니다.
